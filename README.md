# synthalorian.github.io

Personal site — Blackshield mercenary. Iron ground, bone text, blood-red cross. The knight holds the field.

**Live:** https://synthalorian.github.io

## What it is

Static portfolio on GitHub Pages. Single page, live GitHub stats, featured projects, and the Blackshield visual system. Knight A, the Blackshield Company mascot, stands in the bottom-left corner — idle by default, hover or focus to raise the shield, click (or Enter/Space) to swing the sword, and he falls to thinking after a while with nothing happening.

## Layout

- `index.html` — the page
- `css/style.css` — the only stylesheet
- `js/main.js` — stats, theme toggle
- `js/knight.js` — the corner knight (states, hover, click, inactivity)
- `img/knight/` — Knight A animated SVGs: idle, success (shield raised), working (sword swing), thinking
- `img/knight-a-companion.png` — the earlier Knight A sheet, no longer referenced
